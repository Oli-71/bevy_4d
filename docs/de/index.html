Hyperspace und Quantenverschränkung

Wie sähe unsere Welt aus, wenn man sie aus einer 4D-Perspektive betrachten könnte?
Hier können Sie es ausprobieren!

Die Simulation besteht aus sechs Szenen. Bitte lesen Sie immer zunächst den Text, bevor Sie mit den Parametern experimentieren.

Bleibt zu überlegen, ob eine höhere räumliche Dimensionen nur Gehirnakrobatik ist oder ob es sie geben kann oder gar geben muss? Siehe dazu einen Essay über die Absurdität der Quantenwelt. Ein 4D-Wurmloch - wie am Ende der Simulation angedeutet - könnte das Dilemma der Nicht-Lokalität lösen...

Auf die Idee zu dieser Simulation brachten mich der Roman Quantum Space von Douglas Phillips und Edwin Abbott's berühmte Novelle Flatland.

Viel Vergnügen!
