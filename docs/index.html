Hyperspace und Quantenverschränkung

Wie sähe unsere Welt aus, wenn wir sie aus einer 4D-Perspektive betrachten könnten?
Hier können Sie es ausprobieren! Auf die Idee zu dieser Simulation brachte mich der Roman 'Quantum Space' von Douglas Phillips. Starten wollen wir auf den Spuren von Edwin Abbott. In der Novelle 'Flatland' demonstriert Abbott, wie schwierig es ist, sich etwas völlig neues vorzustellen:
Wie würde ein Bewohner einer zweidimensionalen Welt dreidimensionale Objekte wahrnehmen?

Die Simulation besteht aus sechs Szenen. Bitte lesen Sie immer zunächst den Text, bevor Sie mit den Parametern experimentieren.

Bleibt zu überlegen, ob eine höhere räumliche Dimensionen nur Gehirnakrobatik ist oder ob es sie geben kann oder gar geben muss? Siehe dazu einen Essay über die Absurdität der Quantenwelt. Ein 4D-Wurmloch - wie am Ende der Simulation angedeutet - könnte das Dilemma der Nicht-Lokalität lösen...

Viel Vergnügen!
